# Warbound Horizon

Plaintext

Create a modern, clean, and interactive single-page landing page inspired by the game War Thunder, featuring a sleek dark-mode UI with high-tech tactical aesthetics.

Key Requirements & Sections:

1. Visual Style & Theme:
- Theme: War Thunder (Military Aviation, Tanks, Naval Combat).
- Aesthetics: Ultra-clean, premium dark mode, glassmorphism, subtle neon accents (steel blue and orange).
- 3D Interactive Hero Canvas: A 3D rendered interactive space in the hero section displaying a customizable military vehicle model (e.g., fighter jet or main battle tank) using Three.js/React Three Fiber. Users should be able to rotate, zoom, and customize simple colors/decals on the 3D model.

2. Navigation Bar:
- Clean floating glassmorphism navbar.
- Links: Home, About, 3D Customizer, Reviews, AI Tactical Assistant, Download.
- CTA Button: "Download Now" (highlights in military orange).

3. Hero Section:
- Bold headline: "Experience True Combat Realism".
- Subtitle: "Dominate land, air, and sea in the ultimate free-to-play military vehicle simulator."
- Interactive 3D Model viewer in the center with interactive controls (Rotate, Zoom, Change Camo/Skin).
- Primary CTA: "Play Free on Steam" -> Links externally to: https://store.steampowered.com/app/236390/War_Thunder/

4. About Section:
- Interactive cards/tabs detailing War Thunder features: Air Combat, Ground Forces, Naval Warfare, and Realism & Ballistics.
- Sleek stats counter (e.g., "2,000+ Vehicles", "Millions of Players", "Detailed Ballistics").

5. AI Tactical Assistant Component ("WT Tactical AI"):
- An interactive chatbot widget embedded on the page.
- Pre-loaded with quick actions/prompts: "Best starter tank?", "Air Combat Tips", "System Requirements".
- Simulated AI interface with realistic streaming response feel and clean chat UI.

6. Reviews & Player Testimonials:
- Grid layout with glassmorphism cards.
- Player avatars, star ratings, quote badges, and Steam reviewer tags.

7. Download & CTA Section:
- Prominent "Ready for Battle?" banner.
- "Download on Steam" primary button directing strictly to: https://store.steampowered.com/app/236390/War_Thunder/
- System Requirements accordion list (Minimum & Recommended specs).

8. Footer:
- Disclaimer: Fan-made landing page experience. Trademarks belong to Gaijin Entertainment / War Thunder.
- Quick links & social icon placeholders. add animated war thunder backgrounds also and make it look professional
